# K4 partial 第五轮：高频属性与显隐边界

## 基线与优先级

基线 `0f26583`，与开始时本地最新 `oc/integrate` 一致。第四轮剩余 **95** 项
partial，在 53 份只读语料中按类型出现次数加权 **8420** 次。频率是积木节点数，
不是作品数，也不是执行次数。本轮继续按频率×可独立修复成本选择：

|候选|语料次数|本轮决策|
|---|---:|---|
|`get_3`，以及 `get/get_2` 别名|2049 / 0 / 0|最高频；拆出列表引用、惰性槽和无造型 getter，成本可控，优先修复并逐帧/像素验证|
|`self_set_effect_2 / self_change_effect_3`|1228 / 735|跨平台 ASCII、shader 与 ELASTIC 成本高；不冒充已解决|
|`set_actor_as`|1051|接触/复杂轮廓/软体涉及共用求解器，保留边界|
|`physics2_enable_force / set_velocity`|317 / 250|跨求解器轨迹与接触，未在本轮扩大修改|
|`stamp / image_stamp`|308 / 165|字体/纹理/raster 全量像素，成本高|
|云变量 get/set/change 与云列表|296 / 159 / 114 等|在线权限、并发和持久化不能由离线探针证明，跳过|
|`set_scene_transition`|215|distort 与完成回调涉及调度和渲染，保留|
|`get_clone_index_property`|162|与最高频属性共享独立分派，同步修复列表引用及惰性槽|
|`set_entity_show_hide`|64|渐变 update 相位、竞争和取消可用离线原创探针验证，作为第二专项|
|需摄像头、录音、MIDI、硬件的类型|若干|遵循已确认设备边界，不用离线固定返回值冒充设备支持|

完整第四轮排序与成本取舍保留在 [上一轮记录](kitten4-partial-4.md)，
本轮不会通过改分类口径、跳过失败样本或删除未验证限制来降低 partial 数。

## 专项证据

- [属性列表引用、惰性 UUID 槽、无造型 getter](kitten4-partial-properties-5.md)：
  8 份原创夹具，96 个官方 update，40 对固定帧零差异画布；默认 JIT 与解释器
  对每帧状态回归，并验证重启不泄漏惰性槽。
- [显隐渐变](kitten4-partial-visibility-5.md)：按官方实际 update、alpha 和调用
  尾部的执行帧核查，17夹具408帧；407对画布零超差，保留第8帧克隆提前删除
  导致的一对1600像素差异，不以同一终态代替逐帧语义。

各专项中列明未完成或未验证分支。只读官方 `.orig` SHA-256、夹具 hash、状态与
像素指标保存在对应证据 JSON；官方包、第三方作品与第三方截图不入库。
没有移植官方源码，也没有参考或移植 HateNeko 代码。

## 统计口径

本轮缩小已知 partial 的具体语义缺口，而不是将有剩余平台/非有限/取消分支的
类型整体改成完全支持。覆盖表更新具体边界和证据，保留 partial 类型数 **95**、
出现次数加权 **8420**；这不否定已修复的子范围，也不等同作品成功率。

全量门禁、语料三 seed 及最终提交结果见 worktree 根目录不提交的 `OC-REPORT.md`。
