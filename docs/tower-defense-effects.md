# M4 特效与性能

原生池新增12弹体、12复用冲击/升级光环、1个Boss横幅，总计65角色。弹体SVG自带拖尾、朝目标旋转；命中轻微缩放反馈，6槽伤害数字文字印章；升级脉冲0.6秒；漏怪触发有限屏幕震动。伤害结算始终由核心执行，不依赖可见弹体。

性能处理：塔显示约16Hz、敌人约40Hz、弹体/光环约28Hz请求上限，实际取决于官方调度。低画质关闭光环/数字/震动，缩小弹体；隐藏光环脚本降至5Hz。控制器实测低于30更新FPS累计3秒则自动转低画质。

发现亮度滤镜0在官方渲染器中是黑色，不是默认亮度，而且为所有敌人持续启用滤镜显著降低rAF。最终删除该滤镜，改用缩放反馈；压力场景rAF由约57提高至约76Hz。保留失败阶段的测量记录以说明改动原因。
