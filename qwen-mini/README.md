# 迷你 Qwen 故事机

按 Qwen2 结构缩小的字级中文模型，推理全部是原生积木，在 NekoC 播放器里运行。

- 结构：6 层，隐藏 128 维，4 个查询头 / 2 个 KV 头（GQA），RoPE，SwiGLU（384），RMSNorm，QKV 偏置，词嵌入与输出层共享。
- 规模：约 138 万参数，字级词表 1,502 个字，上下文 256。
- 权重：按行 int8 量化，存在作品列表 `lm_w`；行缩放、偏置、归一化权重和 RoPE 表存在 `lm_f`。

## 环境

- Python 3.10 以上，安装 `torch` 和 `numpy`。
- NekoC 仓库能编译：装好 Rust、Node，并在仓库里执行过 `npm install`。

## 步骤

所有命令都在本目录执行，中间文件写在当前目录。

1. 准备数据。会下载 52AI/TinyStoriesZh 的 1M 版（约 260MB）。只保留全部用常用字写的故事，约 24 万篇、5,560 万字。

   ```bash
   python prep.py
   ```

2. 训练。有 CUDA 或 Apple MPS 时会自动使用，每 1000 步保存一次 `ckpt.pt`。
   - 4 核 CPU 上每步约 0.4 秒，1 万步约 1 小时多一点。
   - 用显卡可以加大批量，例如 `--batch 128 --steps 20000`。
   - 中断后用 `--resume` 接着训练。

   ```bash
   python train.py --steps 10000
   ```

3. 生成作品。脚本会量化权重、生成积木 TS，再调用 NekoC 编译成 `out/qwen_mini.bcmkn`。`--prompt` 用来打印 Python 参考实现的贪心续写，可以和播放器里按 T 切到贪心后的结果对照。

   ```bash
   python build.py --nekoc ../NekoC --prompt 从前，有一只小猫
   ```

## 操作

| 按键 | 作用 |
|---|---|
| 1 / 2 / 3 | 预设开头 |
| 回车 | 自定义开头（只能用词表里的字） |
| R | 换随机种子重写 |
| T | 切换贪心 / 采样（温度 0.8，丢弃概率低于最高概率 10% 的字） |
| 空格 | 算完当前字后停止 |

播放器设置里把“每帧预算”调大（例如 12ms），生成会明显变快。

## 文件

| 文件 | 内容 |
|---|---|
| `model.py` | PyTorch 模型和配置 `CFG`，改规模就改这里 |
| `prep.py` | 下载数据，建词表，切分训练集和验证集 |
| `train.py` | 训练 |
| `export.py` | int8 量化和权重布局，附带按积木算法写的 float64 参考推理 |
| `gen_ts.py` | 生成积木程序（TS）和带权重列表的模板 |
| `build.py` | 串起导出、生成和编译 |
| `base.bcmkn` | 空白舞台和角色模板 |

改了 `model.py` 里的 `CFG` 以后，要从 `prep.py` 那一步之后重新训练。`gen_ts.py` 会按新配置生成积木。规模变大以后，每个字的计算量大约等于参数量（乘加次数），按 VM 每秒约 3,000 万次乘加估算速度。
